# Build Plan — creditlab

> Loan-level mortgage PD modeling on real Fannie Mae data, stress-tested through the 2008 crisis

## Milestones

- [x] **Loader and synthetic fixtures** — Chunked, memory-bounded parser for Fannie Mae acquisition/performance file layouts with schema validation; deterministic synthetic fixture generator mirroring the schema so all tests run offline. *(Done 2026-08-19: `creditlab/schema.py` — classic 25/31-column layouts, typed records; `creditlab/loader.py` — generator-based strict/lenient readers, gzip support, `chunked()`; `creditlab/fixtures.py` — seeded hazard-model generator with crisis multiplier, D90+ progressions, self-curing blips; 17 tests, stdlib-only.)*
- [x] **Default labels and vintage cohorts** — Construct D90+ (and D180) default-within-horizon labels from monthly performance records; group loans into origination-vintage cohorts. *(Done 2026-08-19: `creditlab/labels.py` — streaming per-loan grouping with sortedness guard, D90+/D180 within-horizon labels with explicit censoring (None, never a silent negative), prepay-as-known-negative competing-risk convention, credit-event ZB codes count as default, vintage derived from period−loan_age so no acquisition join needed; per-vintage CohortStats; 17 new tests incl. crisis-vintage signal and determinism.)*
- [x] **Feature engineering** — Origination features (FICO, LTV/CLTV, DTI, loan purpose, occupancy, property type, rate spread at origination), missing-value policy, leakage audit (no post-origination information in features). *(Done 2026-08-20: `creditlab/features.py` — declarative FEATURE_SPEC with per-feature `sources`; `audit_leakage()` enforces the AcquisitionRecord allowlist structurally and runs in CI; explicit missing-value policy (required fields exclude + count, optional fields have documented fallbacks); rate_spread vs bundled annual PMMS benchmark (overridable); streaming acquisition↔label join with full accounting (FeatureStats); deterministic one-hot design matrix in plain lists; 19 new tests — 53 total.)*
- [x] **Logistic baseline with calibration** — Regularized logistic regression; reliability curves, Brier score, AUC, expected-vs-realized default rate by score decile. *(Done 2026-08-20: `creditlab/metrics.py` — hand-rolled, exactly-tested AUC (tie-aware Mann-Whitney), Brier + climatology skill score, quantile reliability curve, decile table; `creditlab/baseline.py` — sklearn-fitted L2 logistic extracted into a self-contained JSON-safe artifact (inference is plain arithmetic, coefficients keyed by feature name for M7 reason codes), EvalReport bundling discrimination + calibration, seeded random_split as the naive benchmark M6 will contrast; fixture model recovers the hazard physics (FICO −, DTI +, collinear LTV block + as a group); 35 new tests — 88 total.)*
- [x] **Gradient boosting challenger** — LightGBM model benchmarked against the baseline on identical splits; document the accuracy-vs-interpretability trade. *(Done 2026-08-20: `creditlab/challenger.py` — dual backend: LightGBM (optional `[gbm]` extra; deterministic single-thread, gain importances, JSON-safe native-string artifact truncated to best iteration) with sklearn HistGradientBoosting fallback (permutation importances, train-in-session only); both train with early stopping — unchecked boosting on small data produced confidently miscalibrated probabilities, caught by the Brier-skill test; ModelComparison reports AUC/Brier deltas + the interpretability trade on identical splits. Note: on fixtures the logistic baseline wins (~0.05 AUC) because the synthetic hazard IS logistic — the correctly-specified model beats the ensemble, documented in-test; real-data verdict is M6's question. 14 new tests — 102 total (2 lightgbm-specific, run in CI).)*
- [x] **Crisis out-of-time validation** — Train on pre-2007 vintages, validate on 2007-08 vintages; PSI drift metrics; headline README table showing calibration degradation. *(Done 2026-08-20: `creditlab/validation.py` — split_by_vintage OOT split, PSI with training-population quantile bins + zero-proportion flooring (hand-computed exact test), per-feature PSI, crisis_validation running naive random split vs honest OOT side by side with the same trainer; CrisisReport with underprediction ratios, top drifted features, markdown headline_table. Fixture results in README: discrimination survives (AUC 0.874→0.826) while calibration breaks (realized/predicted 1.31 OOT vs 0.80 naive); drift attributed to rate variables (orig_rate PSI 0.20) not borrower quality (fico 0.04). Works with the GBM trainer too — no more clairvoyant. 18 new tests — 120 total.)*
- [ ] **Adverse-action reason codes and fairness audit** — Per-applicant top negative factors (ECOA-style reason codes) and a proxy-fairness audit over the available non-protected attributes.
- [ ] **Tearsheet report, CLI, and CI** — creditlab CLI (ingest/train/validate/explain/tearsheet/demo), self-contained HTML report, offline test suite green in CI, `creditlab demo` reproduces the README numbers.

## Architecture

loader (chunked pipe-delimited parsing of Fannie Mae acquisition/performance files, schema-checked; synthetic fixture generator mirrors the schema) -> labels (D90+ default within horizon, vintage cohorts) -> features (origination: FICO, LTV, DTI, purpose, occupancy, rate spread) -> models (logistic baseline; gradient boosting) -> validation (vintage-based out-of-time split incl. 2007-08 crisis vintages; AUC, Brier, reliability curves, PSI drift) -> explainability (adverse-action reason codes, proxy fairness audit) -> tearsheet (HTML/Markdown report; `creditlab demo` reproduces README numbers offline)
